# 浏览与评分

## 动画、角色、人物

### 动画详情

点击动画海报进入详情页。这个页面展示简介、基本信息、剧集、标签、主要角色、关联条目和海报。  
如果你之前是“番组计划”的用户，应该会对这个界面很熟悉。

点击标签可以查看这个标签下的所有动画。点击顶栏的标签，可以查看本地收录的全部标签。

详情页的“关联条目”不会主动拉取。Seshat 只拉取你明确指定的条目。

在评分卡片上方，可以切换到剧集、角色、制作人员的详细列表。  
点击相关角色或人物，会跳转到他们的详情页。

#### 展示你的“番组计划”数据

如果你在“番组计划”维护你的数据，那么可以在设置页面的“Bangumi 用户 ID”中填写你的 ID。

保存后，在“管理数据”页面点击“刷新用户数据”，即可展示你的账户数据。
例如你对动画的打分、标记的状态等。

### 角色和人物详情

这两个页面共用一套样式，会显示简介、基本信息、海报。  
角色页会展示出演过的动画和 CV。人物页会展示出演过哪部动画的什么角色，以及参与制作的条目。

点击顶栏的角色或人物按钮，可以查看本地收录的全部内容。

## 搜索

点击顶栏的搜索按钮，或者按下 `/` 键，可以进入搜索页面。  
搜索会遍历本地储存的所有数据来匹配关键词。

搜索时间根据你勾选的筛选器，与你本地的数据量而定，通常在近乎瞬间到数秒。

## 评分

这是 Seshat 的本地功能。当你拉取了超过 2 部动画，就能对动画进行评分。

评分使用标准 ELO 机制，初始均为 1500 分。  
每次评分会随机派发两部动画，你选出认为更好的一部。打分越多，统计越准确。  
最终结果可以在“统计”页面查看。

### ELO 排除名单

如果不希望某些条目出现在评分配对中，可以编辑主目录下的 `user/elo/exclude.toml`：

```toml
ids = [184740, 123456]
```

支持多行逗号分隔，格式与 Tracker 一致。修改后刷新评分页即可生效。

### 删除评分记录

删除主目录 `user/elo/history.json` 中对应的记录，然后重建 ELO。

## 统计

条目统计记录本地每个分类的条目数量。

评分统计默认按 ELO 分数排序，没有分数的条目不会展示。  
可以在标题旁边的排序和显示设置中调整展示方式。

ELO 分数旁边的百分比，是这个条目在本地所有 ELO 分数中的排名位置。

## 设置

标题展示方式控制页面标题的内容。大多数页面都支持这个设置。  
默认为原文优先，即大标题原文，副标题中文。设置为中文优先后，两者位置互换。

条目名称高亮控制详情页简介和数据栏中，是否高亮本地已有的条目。  
如果本地数据非常多，详情页加载需要 0.5 秒甚至数秒，可以关掉它来降低加载时间。

## 其他条目

Seshat 设计为“动画”的离线数据浏览工具。  
但“番组计划”中的游戏、音乐、书籍等也都是“条目”，所以也可以拉取这些内容。  
前端会尝试渲染它们。
