# 配置

程序运行时，会从环境变量中读取 `SESHAT_HOME` 作为程序的主目录。  
和程序运行相关的数据，都会存放在这里。  
`SESHAT_HOME` 未设置时，使用 `~/.vSoft/Seshat` 作为主目录。

程序第一次运行，会在主目录生成 `config.toml` 配置。  
所有配置项均已添加注释，你可以按需修改。  
如果你不了解每个配置的实际用途，请勿修改。

所有需要手动修改的配置文件，都为 `toml` 格式。  
请不要，也无须手动修改 `json` 格式的数据。

## bind_addr（监听地址）

若只在本机访问，默认值 `127.0.0.1` 即可。  
设为 `0.0.0.0` 可将服务开放到局域网。  
请仅在安全局域网环境中开放访问，切忌将其映射至公网。

## data_home（数据目录）

数据目录默认存放在主目录的 `/data` 中，这里存放从上游拉取的 Json 和图片数据，以及 Seshat 索引。  
数据目录的大小，视乎你拉取的条目数量。每个包含图像等周边信息的条目大约 20 MB（仅供参考）。

## concurrency（并发任务）

这控制任务的并发数，并非 HTTP 请求的并发数。  
每个任务中会有 4 到 7 个 HTTP 请求，因此请勿设置过高。

## base_url（上游地址）

这控制后端拉取数据时的请求位置，默认为“番组计划”的 API 端点。  
留空将不能拉取数据，建议不动。

## backend_url（后端地址）

这控制前端请求数据时，访问的后端地址。默认为留空，将请求本地后端/api/v0。

得益于 Seshat 后端的大部分数据 API，都和“番组计划”返回值几乎一样。  
若将此项设为 `https://api.bgm.tv`，前端就可以直连“番组计划”。  
但不建议，因为 Seshat 的目的是离线查看动画数据库，直连在线后端与 Seshat定位不符。

### 行为

这里解释当 Seshat 直连“番组计划”时的特殊行为：

- 仍会请求本地后端的索引，用于展示首页的海报墙。
- 标签列表、统计、评分、设置页面将不再可用。
- 搜索标签将不再可用。
- 对于设置了用户名的用户，海报墙的状态角标将仅能展示极少部分。

## fallback_url（回退地址）

当请求后端时返回 404 时，将回退到此地址。默认为留空，不启用回退。

若将此项设为 `https://api.bgm.tv`，在本地没有保存某些数据的时候，就能够自动回退到在线端点。  
这使得在有网络的情况下，可以查看到更多数据。

要开启回退，建议先在不设置回退的情况下，完整拉取一遍数据后再开启，确保本地数据正常。
